# FIT90 — World-Class Premium Lifestyle Transformation Platform

A modern, high-performance website for **FIT90**, designed with an award-winning editorial aesthetic:
**WARM MINIMALISM × SOFT ANIMATED GRADIENTS × BESPOKE EDITORIAL DESIGN.**

---

## Brand Positioning & Concept

> **"90 DAYS. A DIFFERENT YOU."**

FIT90 is an intentional 90-day lifestyle transformation architecture that aligns physical movement, metabolic nutrition, daily non-negotiables, and restorative recovery into a permanent standard.

### Key Design Elements
- **Multi-layer Animated Background**: Continuously shifting, GPU-accelerated organic mesh gradient orbs with subtle tactile grain texture.
- **Layered Hero Section**: Large editorial display typography, floating live protocol card, and animated SVG progress ring.
- **Interactive 90-Day Journey**: 3 chapters (Foundation, Progression, Transformation) with dynamic atmospheric theme transitions.
- **Digital Member Sanctum**: Interactive rest interval timer (01:30), live meal macro tracking, habit checklist, and compound strength PR vault.
- **Authentic Transformation Stories**: Touch/mouse-draggable Before & After split slider with documented biometric progress.
- **Transparent Tuition & Frictionless Checkout**: Multi-currency ($297 / ₹14,999) toggle, Card, Apple Pay, and UPI support with instant Day 00 onboarding directives.

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom keyframe animation engine
- **Typography**: Instrument Serif, Cormorant Garamond, Plus Jakarta Sans, Manrope, JetBrains Mono
- **Motion**: Framer Motion & CSS GPU Transforms
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/akshatsinha/fitbasic.git

# Navigate to project folder
cd fitbasic

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
